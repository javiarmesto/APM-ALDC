### Archive method

The default APM 0.27 plugin pack maps prompts to `commands/`; that format is not
used as Copilot Chat or Copilot CLI E2E evidence. The tested Copilot archive was
created from a clean producer project that depended on this branch, then packed
as an APM bundle with the union of the Copilot runtime and shared Agent Skills:

```bash
apm pack --format apm --target copilot,agent-skills \
  --archive --archive-format tar.gz --verbose
```

APM 0.27 currently directs legacy-format archives to `apm unpack`; both clean
fixtures deployed all 121 files with integrity verification before scaffolding.
